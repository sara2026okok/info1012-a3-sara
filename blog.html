Troubleshooting Blog

Bug 1: Delete Button Not Working

Date: 2026-11-10 14:30

Problem: When I clicked the delete button, it always deleted the last task instead of the one I clicked. Here is the code:

delBtn.onclick = function() {
    taskArray.splice(i, 1); 
};

Solution Date: 2026-11-10 16:00

Cause: The variable 'i' in the loop was changing before the button was clicked. This is a closure issue.

Fix: I used an immediately invoked function expression (IIFE) to capture the current index.

delBtn.onclick = function(index) {
    return function() {
        taskArray.splice(index, 1); 
    };
}(i);

Bug 2: Invalid Date Accepted

Date: 2026-11-12 10:00

Problem: Users could add tasks with dates in the past.

Solution Date: 2026-11-12 11:30

Cause: I forgot to compare the input date with the current date.

Fix: I added a check using `new Date()` to compare dates and show an error message.

var inputDate = new Date(date);
var today = new Date();
if (inputDate < today) {
    errorMsg.innerText = "Due date cannot be in the past.";
    return;
}
