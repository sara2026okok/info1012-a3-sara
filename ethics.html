Ethics and Privacy Reflection

Data Privacy

Privacy is very important. In my app, all user data (tasks and descriptions) is saved directly in the browser using LocalStorage. This means the data is never sent to a server. Only the user can see their own tasks on their own computer.

Ethical Data Use

I only collect the data that is strictly necessary to manage a task (Title, Course, Date, and Description). I do not ask for personal information like phone numbers or addresses.

Implementation Examples

  • Access Restriction: The task management page is protected by a basic login system. This prevents unauthorized people from easily seeing the tasks.
  • Input Validation: The app validates user inputs, like checking for invalid dates. This keeps the data organized and prevents errors.
  • Data Deletion: Users have full control to delete their tasks at any time, respecting their right to remove their data.
